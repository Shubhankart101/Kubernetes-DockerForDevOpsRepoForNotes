# Kubernetes and Docker Script Library

Apply Kubernetes examples with `kubectl apply -f` and build Docker examples with `docker build`.

## Levels

- `beginner/01-10`: Pods, Services, Deployments, configuration, secrets, jobs, namespaces, and Docker basics.
- `intermediate/11-20`: probes, resources, autoscaling, ingress, policy, storage, jobs, and rollout strategy.
- `advanced/21-34`: topology, security, quotas, admission, runtime isolation, multi-stage builds, Compose, Helm, and backup.

Render the main chart with `helm lint helm/devops-app` and `helm template devtrack helm/devops-app`.
